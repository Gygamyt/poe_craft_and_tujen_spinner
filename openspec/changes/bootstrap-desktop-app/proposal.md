# Каркас PoE Autocraft

## Why

В репозитории есть минимальная точка входа TypeScript и конфигурация OpenSpec. Для разработки PoE Autocraft нужна запускаемая оболочка и проверяемые границы между интерфейсом приложения и логикой крафта.

## What Changes

- Подготовить Electron-приложение с Vue 3 и Vite, настроить TypeScript, ESLint, Prettier и Vitest.
- Определить контракты калибровки инвентаря и Currency Stash, парсинга текста предметов и построения плана крафта. Использовать Zod для проверки входных структур на границах.
- Добавить `AGENTS.md`, инструкции запуска, архитектурные решения и журнал текущего состояния в `docs/`.
- Ограничить итерацию оболочкой, контрактами и проверками на тестовых данных. Вне объёма — UI калибровки, полноценный парсер, правила и выполнение крафта, взаимодействие с клиентом PoE и установщики.

## Capabilities

### New Capabilities

- `desktop-shell` — запуск и сборка оболочки, проверки проекта и процесс сопровождения.
- `crafting-contracts` — контракты данных и операций будущего процесса крафта.

### Modified Capabilities

Нет. Это первое изменение проекта.

## Impact

После согласования потребуется расширить существующие конфигурации TypeScript и npm, заменить демонстрационную точку входа и добавить исходники, проверки и документацию. Первый ручной запуск планируется проверить на Windows, где расположен текущий репозиторий.
