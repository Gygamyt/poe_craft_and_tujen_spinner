## ADDED Requirements

### Requirement: Запускаемая desktop-оболочка
Приложение SHALL открывать окно Electron с интерфейсом Vue 3 в режиме разработки и после локальной сборки.

#### Scenario: Запуск в режиме разработки
- **WHEN** разработчик устанавливает зависимости из lockfile и выполняет `npm run dev`
- **THEN** Electron открывает окно с экраном PoE Autocraft, загруженным из Vite

#### Scenario: Запуск собранного приложения
- **WHEN** разработчик выполняет `npm run build` и затем `npm start`
- **THEN** Electron открывает тот же экран из собранных файлов при выключенном Vite dev-сервере

#### Scenario: Изоляция окна
- **WHEN** Electron создаёт окно приложения
- **THEN** renderer работает с изолированным контекстом, включённым sandbox и отключённым доступом к Node.js

### Requirement: Воспроизводимые проверки проекта
Проект SHALL предоставлять отдельные npm-скрипты для проверки типов TypeScript, линтинга ESLint, проверки форматирования и однократного запуска Vitest.

#### Scenario: Проверка на чистой установке
- **WHEN** разработчик выполняет `npm ci`, затем `npm run typecheck`, `npm run lint`, `npm run format:check` и `npm test`
- **THEN** проверки охватывают соответствующие исходники и завершаются с кодом 0 при корректном состоянии проекта

### Requirement: Документированный порядок изменений
Репозиторий SHALL содержать `AGENTS.md`, инструкции запуска и проверки, записи архитектурных решений и `docs/progress/current-state.md`.

#### Scenario: Закрытие задачи
- **WHEN** проверка задачи успешно завершена
- **THEN** исполнитель отмечает задачу в `tasks.md` и записывает результат в `docs/progress/current-state.md`

#### Scenario: Проверка отсутствует или завершилась ошибкой
- **WHEN** проверку выполнить не удалось или она завершилась ошибкой
- **THEN** задача остаётся открытой, а причина отражается в журнале состояния
