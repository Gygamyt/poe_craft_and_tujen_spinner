# Текущее состояние PoE Autocraft

Изменение OpenSpec — `bootstrap-desktop-app`.

## Исходное состояние

- Минимальный проект TypeScript с демонстрационной точкой входа и npm lockfile.
- Схема OpenSpec `spec-driven`, две спецификации и согласованный список задач.
- В индексе Git уже был `.DS_Store`.

## Проверки

- Задача 1.0 — исходное состояние сверено с Git, конфигурацией npm и файлами OpenSpec.

## Подготовлено к проверке

- 1.1–1.4 — конфигурации TypeScript и npm, Electron main и preload, Vue renderer, скрипты Vite, ESLint, Prettier и Vitest.
- 2.1–2.3 — Zod-схемы калибровки и контракты предмета, парсера и планировщика, тесты на синтетических фикстурах.
- 3.1 — `AGENTS.md`, руководство разработчика и запись архитектурного решения. Пути и скрипты в руководстве сверены с рабочей копией.

## Осталось проверить

- 1.1–1.4, 2.1–2.3 и 3.2 остаются открытыми. В сессии недоступны npm и OpenSpec CLI, запрос к npm registry завершился `EACCES`. `package-lock.json` ещё соответствует исходному проекту.
- При доступном npm выполнить `npm install` для обновления lockfile, затем `npm ci`, типизацию, линтинг, проверку форматирования, тесты, сборку и оба запуска Electron на Windows при закрытом клиенте PoE.
- Выполнить `openspec validate bootstrap-desktop-app --strict`.
