# 0001. Границы desktop-приложения

Связанное изменение — `bootstrap-desktop-app`.

## Контекст

Приложению нужна оболочка Electron и предметные контракты, которые можно проверять в Node на фикстурах.

## Решение

- Main владеет жизненным циклом окна. Preload резервирует точку входа для будущего моста. Vue renderer работает с изолированным контекстом, sandbox и отключённым Node.js integration.
- electron-vite собирает main, preload и renderer. В разработке окно загружает Vite, при обычном запуске — локальные файлы сборки.
- `src/domain/` содержит Zod-схемы и типы операций. Калибровка использует сетку для инвентаря и именованные прямоугольники для Currency Stash. Слоты отсчитываются от начала области вкладки.
- Контракт парсера возвращает предмет или типизированную ошибку. Контракт планировщика возвращает упорядоченные намерения применить валюту либо причину отсутствия плана. Реализации для проверки контрактов живут в тестах.

## Последствия

Vitest может проверять предметный слой без окна Electron. Оболочку нужно проверить в двух режимах запуска, поскольку они загружают интерфейс из разных источников.
