# Разработка PoE Autocraft

Начинай навигацию с [карты кода](code-map.md): там указаны границы фич, публичные точки входа и профильные проверки.

[Стенд ввода](input-testbed.md) проверяет движения мыши и синтетические действия отдельно от игры и сохранённой калибровки.

Настройка оверлея описана в [руководстве калибровки](calibration-overlay.md), формат сменяемых раскладок — в [описании шаблонов](calibration-layouts.md).

Для запуска нужны Node.js 24 и npm. Команды выполняются из корня репозитория.

## Установка и запуск

Установи зависимости из `package-lock.json` и открой окно разработки. Скрипт `postinstall` загружает бинарник Electron; для первой установки нужен доступ к сети, повторные установки могут использовать локальный кэш.

```sh
npm ci
npm run dev
```

Закрой окно разработки и останови dev-сервер. Собери и запусти приложение из локальных файлов.

```sh
npm run build
npm start
```

В обоих режимах должно открыться окно Electron с заголовком PoE Autocraft. Проверка выполняется при закрытом клиенте игры.

## Проверки

```sh
npm run typecheck
npm run lint
npm run format:check
npm test
npm run test:calibration
npm run test:crafting
```

`npm run format` форматирует исходники, тесты и конфигурацию. Vitest запускает проверки контрактов в Node.

Текущие результаты проверок и статус lockfile приведены в [журнале](progress/current-state.md). Границы приложения описаны в [архитектурном решении](architecture/0001-desktop-boundaries.md).
